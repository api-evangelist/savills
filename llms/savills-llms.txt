# Savills

> Savills plc is a London-headquartered global real estate advisor, founded in 1855 and listed on the London Stock Exchange, with more than 42,000 people in over 70 countries. It works the advisory side of the property value chain — commercial and prime residential agency, transaction advisory and capital markets, valuation, building and project consultancy, property and facilities management, rural advisory, occupier services, the Savills Research programme, and the separate fund manager Savills Investment Management. Savills publishes no public API.

This file was generated by the API Evangelist enrichment pipeline from Savills' own public web properties and from live probes of its hosts. Savills does not publish an llms.txt of its own; https://www.savills.com/llms.txt, https://www.savills.co.uk/llms.txt and https://search.savills.com/llms.txt all return 404. method: generated.

## APIs

None. Savills publishes no documented public API, no developer portal, no machine-readable contract, no SDK and no Postman collection.

- `developer.savills.com`, `developers.savills.com`, `docs.savills.com` and `apis.savills.com` do not resolve in DNS.
- `api.savills.com` resolves and answers in JSON, but returns `{"statusCode": 404, "message": "Resource not found"}` on every path probed — an API gateway with no public routes. `/openapi.json`, `/swagger.json`, `/v1/openapi.json`, `/api-docs`, `/docs`, `/redoc` and `/graphql` are all 404.
- `/developers`, `/api`, `/docs`, `/openapi.json`, `/swagger.json` and `/api-docs` return 404 on `savills.com`, `savills.co.uk` and `savills.us`.
- Internal services exist but are undocumented and closed. `https://search.savills.com/js/endpoints.js` names four of them — `livev6-searchapi.savills.com`, `livev6-authentication.savills.com`, `livev6-profile.savills.com` and `assets.savills.com`. Each returns 404 to an anonymous client and none serves an OpenAPI, Swagger or OData `$metadata` document.
- The `/.well-known/` discovery surface is empty across all ten Savills hosts: no `security.txt`, no `openid-configuration`, no `oauth-authorization-server`, no `api-catalog`, no `ai-plugin.json`.

## Machine access posture

- `https://www.savills.com/robots.txt` (HTTP 200) allows general crawling but explicitly disallows `CCBot`, `AMAZONAWS`, `SemrushBot`, `SemrushBot-SA`, `BUbiNG` and a legacy `DigExt` agent from the whole site. Disallowing CCBot is the only machine-access statement Savills publishes.
- The sitemap at `https://www.savills.com/sitemap.xml` (HTTP 200) contains no `developer`, `/api`, `swagger` or `openapi` paths.
- There is no `security.txt`, no vulnerability-disclosure programme and no trust centre.
- No RESO Web API or Data Dictionary certification exists; RESO is a North American NAR/MLS construct and the United Kingdom has no MLS to certify against.
